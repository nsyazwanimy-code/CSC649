# CSC649 Python Setup Experiment

## Description

This is my first Python experiment for CSC649. The program asks the user to enter a sentence and displays the word count and character count. It also displays a message when the user enters an empty sentence.

## How to Run

1. Open the project in PyCharm.
2. Make sure Python 3.12.10 is selected as the project interpreter.
3. Open the main.py file.
4. Click the Run button.
5. Enter a sentence when prompted.

## Test Results

### Test 1: Normal Sentence

Input:
I like learning Python

Output:
Word count: 4
Character count (including spaces): 22

### Test 2: Empty Input

Input:
No input was entered.

Output:
You did not enter a sentence.

### Test 3: Extra Spaces

Input:
I   like   Python

Output:
Word count: 3

The program correctly counts the words even when extra spaces are entered.

## Limitation

One limitation of this program is that the character count includes spaces. Therefore, extra spaces will increase the character count."# CSC649"
